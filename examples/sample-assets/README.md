# Synthetic v1.1 sample assets

This directory contains a generated, synthetic `.ioayn/` workspace for a two-function C example. It demonstrates:

- Goal and bounded Slice;
- contextual entity roles;
- FACT and INFERENCE claims;
- Evidence and deferred Unknown;
- checkpoint and learner answer;
- LearningSession, Journal, Round, and LearningAsset;
- system-area, concept, slice, asset, and selected code-entity Atlas nodes;
- a committed round transaction.

The sample deliberately includes normally gitignored personal/runtime directories so developers can inspect the complete v1.1 model. A real target project should follow `.ioayn/.gitignore` and review assets before sharing them.

The source file used to generate the sample is not part of the IOAYN framework and the Git commit hash is only a synthetic revision anchor.
